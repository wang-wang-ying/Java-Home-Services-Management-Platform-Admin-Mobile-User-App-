# Java-Home-Services-Management-Platform-Admin-Mobile-User-App
# 家政服务平台
项目采用前后端分离架构，包含后台管理端和用户手机端，围绕真实家政服务业务流程设计，涵盖服务管理、预约下单、订单派单、服务结算、评价管理等核心功能。

### 1、💻 技术栈：
🔹 Java 21 + Spring Boot 2.7

🔹 Vue3 + Element Plus

🔹 UniApp + Vue3

🔹 MySQL 8.0

🔹 MyBatis-Plus + JWT

🔹 Pinia + Vite + ECharts

### 2、📱 系统包含两大端：

#### ✅ 后台管理端
服务分类、服务项目、订单派单与结算、服务人员、用户管理、评价管理，以及菜单、角色、账号等权限管理。

#### ✅ 用户手机端
登录注册、服务浏览、服务详情、预约下单、订单管理、服务评价、个人中心等功能。

### 3、✨ 项目亮点：
✔ 前后端分离，多端架构设计

✔ 一套后端服务支撑管理端和移动端

✔ 完整的家政服务订单业务闭环

✔ 集成 JWT 身份认证与权限控制

✔ 真实业务场景，适合 Java 全栈实战

✔ 涵盖数据库设计、RESTful API、订单流程等核心知识
